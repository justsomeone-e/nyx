04 / WHAT COMES NEXT

v5.0 is a plan. Evidence makes a release.

RELEASE CANDIDATE

The repository version is 5.0.0-rc.1 (Daydream). Following the stable v4.5 Ivory bridge release, v5 expands direct LLVM IR emission to aggregate types, establishes native self-hosting paths, and connects LLVM directly to the CLI while preserving Typed HIR v1 compatibility.

  1. Direct LLVM IR pipeline

    Native scalar arithmetic, IEEE double, structured control flow, and Clang compilation without C++ hops.

  2. LLVM aggregate types

    Value-semantic structs, stack-owned scalar arrays, bounds verification, element copy semantics, and for-loop iteration.

  3. C17 scalar backend

    Portable ISO C17 emission, wrapping signed integer arithmetic, safe division aborts, and strict conformance.

  4. Toolchain integration

    Direct nyx build -t llvm and nyx run -t llvm workflows compiling directly to native binaries via host Clang.

  5. Memory & ownership

    Heap descriptors, escaping arrays, string runtime, memory cleanup CFG, and safe boundary transitions.

  6. Standard library in LLVM

    Direct lowering of string, collection, path, and process standard library APIs with Result parity.

  7. Reference frontend

    Independent AST and Typed HIR frontend design decoupled from host runtime specifics.

  8. Native self-host bootstrap

    Bootstrapping the self-hosted Nyx compiler through direct native code rather than C++ transpilation.

  9. Release verification gates

    Cross-platform CI matrix (Linux, Windows, macOS ARM/Intel), full regression battery, deterministic SBOM, and release provenance.

Outside v5.0: Go, JVM, .NET and Lua backends, breaking syntax, and retiring C++ before self-host bootstrapping is proven.
