04 / WHAT COMES NEXT

v4.5 is a plan. Evidence makes a release.

IN DEVELOPMENT

The repository version remains 4.0.0. v4.5 work preserves v4 source compatibility, Typed HIR v1 and Bundle ABI v1. These tracks are release requirements, not completed feature claims.

  1. Editor experience

    References, rename, semantic tokens, module navigation and shadowing-aware resolution.

  2. Practical applications

    Native CLI, JS/Python integrations, WASM apps, packages, bindings and larger games.

  3. Measured compilation

    A fixed corpus, per-stage time and peak memory before cache changes; reproducible bootstrap stages.

  4. Standard library

    String, collection, path and process APIs with consistent Result errors and exact stable-target parity.

  5. Rust backend

    Result/Option/control-flow parity, lexical defer, value semantics, tasks and channels with negative tests.

  6. WASM & WASI

    Array/struct ABI, UTF-8 ownership, filesystem/args/environment, separate host profiles and memory stress tests.

  7. Packages & bindings

    Deterministic versioned locks, registry design, typed manifests, offline and checksum verification.

  8. v5 preparation

    Experimental C17/LLVM prototypes, independent frontend design and source/HIR/ABI/lockfile migration guides.

  9. Release gates

    Stable parity, Stage1 → Stage2 → Stage3, platform CI, extension tests, checksums, SBOM and release assets.

Outside v4.5: Go, JVM, .NET and Lua backends, breaking syntax, and a stable LLVM backend.
